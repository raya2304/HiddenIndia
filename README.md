# Hidden India

Hidden India is a responsive travel website that showcases beautiful and lesser-known destinations across India. It features scenic locations, informative descriptions, and an attractive visual layout to encourage users to explore places beyond popular tourist destinations.

## Features

* Explore hidden destinations across India
* Attractive destination images
* Short and detailed location descriptions
* Clean and responsive design
* Easy navigation
* Mobile-friendly layout

## Destinations

* Ziro Valley
* Dhanushkodi
* Majuli
* Hampi
* Lonar Lake
* Chembra Peak
* Mawlynnong
* Spiti Valley
* Kutch
* Orchha
* Indian Coast

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript

## Project Purpose

This project was created to practice frontend development, responsive design, Tailwind CSS, and building an engaging travel website.
